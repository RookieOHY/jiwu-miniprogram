# 记物 · jiwu-miniprogram

> 记录你的物品与日均成本 —— 一件东西用得越久，每天就越便宜。

**记物**是一个微信小程序：以「物品」为单位记录你的每一次购买，自动计算每件物品的**日均成本**（Cost Per Use），帮你回答那个经典问题——

> 我买的这东西，到底值不值？

8000 元的手机用了 999 天，日均 8 元；吃灰的 2000 元跑步机，日均每天都在涨。数字会告诉你答案。

## 功能

- 📦 **物品录入**：名称、价格、购买日期、7 大分类、9 大购买渠道（京东/淘宝/拼多多/唯品会/闲鱼/微信小店/抖音/线下/其他）
- 📉 **日均成本**：实时计算，越用越便宜；支持 30 天 / 一年后的摊销预测
- 📌 **置顶**：长按物品弹出操作菜单（最多 3 件）
- 🗑️ **退役 / 已卖出**：锁定最终日均；记录卖出价，自动算回收差价，复盘真实成本
- 📊 **统计**：近 30 天每日支出、近 6 个月买入趋势、分类与平台占比、日均排行
- 🔄 **双视图**：列表 / 卡片网格自由切换，选择自动记忆
- 🔒 **隐私**：数据全部保存在本机，无需登录，无任何网络请求

## 运行

1. 下载 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（macOS 选 ARM64 / x64）
2. 导入本项目目录，AppID 使用测试号或自己的小程序 AppID
3. 编译即可运行

## 技术栈

- 原生微信小程序（无第三方依赖）
- 数据存储：`wx.setStorageSync` 本地存储
- 图标：Lucide SVG 内联
- 配色：荧光紫主色（`#8b5cf6 → #c084fc` 渐变），CSS 变量 + 深色模式，参考「有数」
